'maintainers.space': minor
---

Adds Community, a chat space for every forge user and organisation, built on atproto and hosted by Colibri. Maintainers set it up from the new Community page and get announcements, general, showcase and support channels, a channel for every repository and one for each team. Every repository gets a Community tab that opens its own channel, anyone can read along without signing in, and members can chat, reply, react, attach files and start forum threads.
