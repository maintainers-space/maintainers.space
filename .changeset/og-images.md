Adds social preview images for shared links. Repositories, issues, pull requests, discussions, owners and profiles each get their own card with names, avatars, states, labels, stats and languages on every forge, over a honeycomb that is unique to each page and tinted by its language or state, and every page now has a real title and description for link previews. Set the optional `NUXT_OG_GITHUB_TOKEN` to give the server a higher GitHub rate limit for these.
